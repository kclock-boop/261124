# 태화기업 업무 플랫폼

업무 홈에서 오늘 할 일, 대기·진행 중인 현장 조치, 저장한 문서 수를 확인할 수 있습니다.

| 메뉴 | 기능 |
| --- | --- |
| 업무 데스크 | 할 일, 평일·주간·월간 반복 업무, 월간 캘린더, 기간 일정, 메모 검색, 업무 문구 저장 및 복사 |
| 현장 안전점검 | 현장 점검, 위험도, 조치 담당자·기한, 조치 전후 사진, 진행 상태와 인쇄 |
| 품의서 작성 | 제목·사유로 초안 작성, 문서 편집, 양식 관리 및 저장 |
| 이모티콘 제작기 | 참여자가 만든 모양 제작기를 그대로 사용 |

압축을 푼 뒤 **Start-Web.cmd** 또는 **Start-App.cmd**를 실행합니다. 업무 데스크는 첨부 화면 기준으로 구현했습니다. 알림은 플랫폼이 열려 있을 때 작동하며, 브라우저에서 시스템 알림을 허용할 수 있습니다. 시간이 있는 일정은 5분 전, 날짜만 있는 일정은 당일 오전 7시 30분을 기준으로 알립니다.

기록은 브라우저 프로필과 접속 주소별로 저장됩니다. 기존 `file://` 화면에 이미 저장한 기록은 해당 화면의 저장 공간에 남아 있습니다.

## 품의서 작성

제목과 사유·메모로 업무 문서 초안을 작성하는 앱입니다. 처음에는 **품의서** 양식이 제공되며 **품의 목적**, **품의 내용**, **구매사양** 세 항목으로 구성됩니다.

- 문서 작성 화면에서 제목과 사유를 입력하고 **AI 초안 작성**을 누릅니다. 미리보기에서 본문을 편집하고 문서를 저장하거나 복사·인쇄할 수 있습니다.
- **양식 관리**에서 회의록, 결재 양식 등을 추가할 수 있습니다. 항목 이름과 항목별 AI 작성 기준을 지정하면 다음 문서부터 재사용할 수 있습니다.
- 현재 작업은 자동 저장됩니다. **문서 저장**을 누른 문서는 **저장한 문서**에서 다시 열 수 있습니다. 저장 문서는 작성 당시의 양식을 함께 보관합니다.

## Windows에서 실행

Node.js 22.9 이상과 Microsoft Edge가 필요합니다. 프로젝트 폴더에서 아래 파일을 두 번 클릭합니다.

| 실행 방식 | 실행 파일 | 열리는 화면 |
| --- | --- | --- |
| 웹 | `Start-Web.cmd` | Edge 브라우저 탭 |
| 앱 | `Start-App.cmd` | 독립된 Edge 앱 창 |

두 파일은 같은 컴퓨터의 `http://127.0.0.1:8888`을 사용합니다. 처음 실행할 때 열린 명령창을 최소화해 두면 AI 기능을 계속 사용할 수 있습니다. 명령창을 닫거나 Ctrl+C를 누르면 로컬 서버가 종료됩니다. 터미널에서 직접 실행할 때는 프로젝트 폴더에서 `npm start`를 실행하고 출력된 주소를 브라우저에서 엽니다.

Windows 시작 메뉴에도 추가하려면 웹 화면의 **앱 설치** 버튼 또는 Edge 주소창의 앱 설치 아이콘을 사용합니다. 처음 화면을 불러온 이후에는 서버가 꺼져 있어도 설치한 앱에서 기존 문서를 열고 수동 편집할 수 있습니다. [Microsoft Edge 웹앱 설치 안내](https://learn.microsoft.com/en-us/microsoft-edge/progressive-web-apps/ux)

## AI 초안 작성 설정

1. `.env.example`을 복사해 같은 폴더에 `.env`를 만듭니다.
2. `OPENAI_API_KEY`에 발급받은 키를 입력합니다. 기본 모델은 `gpt-4o-mini`입니다. Structured Outputs를 지원하는 다른 Chat Completions 모델을 쓰려면 `OPENAI_MODEL`을 변경합니다. [OpenAI Structured Outputs 문서](https://developers.openai.com/api/docs/guides/structured-outputs?api-mode=chat)
3. 로컬 서버를 다시 실행하고 **예시 입력 → AI 초안 작성**으로 확인합니다.

AI 초안 작성에는 로컬 서버와 인터넷 연결이 필요합니다. 키 설정 전에도 문서와 양식을 수동으로 작성하고 저장할 수 있습니다.

## 데이터 위치

양식과 문서는 브라우저의 `localStorage`에 저장됩니다. 같은 Edge 프로필에서 웹과 앱을 사용하면 문서와 양식을 함께 열 수 있습니다. 브라우저 프로필이나 사이트 주소가 달라지면 각자의 저장 공간이 사용됩니다. 브라우저 저장 데이터는 앱에서 별도로 암호화하지 않습니다.

웹과 앱은 **실행한 PC에서만** 접속할 수 있습니다. API 키는 PC의 `.env` 파일에서 로컬 서버가 읽습니다. **AI 초안 작성**을 실행할 때 입력한 제목·사유와 선택한 양식의 항목이 OpenAI로 전송됩니다. 실습에는 예시나 익명화한 정보를 사용하고, 사내 자료의 외부 전송이 제한된 경우에는 수동 작성과 저장을 사용합니다.

OpenAI API에 전송한 데이터는 기본적으로 모델 학습에 쓰이지 않습니다. 기본 설정에서는 입력이나 응답의 일부가 악용 모니터링 목적으로 최대 30일간 보관될 수 있습니다. [OpenAI API 데이터 보관 정책](https://developers.openai.com/api/docs/guides/your-data)
